# Study Program for NumPy and pandas

This workspace contains a simple Python script that demonstrates basic use of
**NumPy** and **pandas**. It prints informative messages to the console at each
step to "notify" you about progress.

Additionally, there are a couple of Streamlit applications you can run to
explore notifications and planning:

- `notify_app.py` – shows how to trigger a browser/desktop notification after
  running some program logic.
- `learning_app.py` – interactive planner that displays a suggested schedule and
  resources based on your chosen learning focus.

## Running the Demo

1. Make sure you have Python 3.8+ installed.
2. Install dependencies:
   ```sh
   pip install numpy pandas
   ```
3. Run the script:
   ```sh
   python study.py
   ```

You will see log messages describing array operations and DataFrame manipulations.

Feel free to edit `study.py` to experiment with other NumPy/pandas features.
